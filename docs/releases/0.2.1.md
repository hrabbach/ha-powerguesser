# PowerGuesser 0.2.1

A small maintenance release on top of 0.2.0. There are no changes to day-to-day detection or the
learning flow: this release carries one behaviour fix and the first full documentation set.

## Fixes

- **Removing the integration now deletes its plug-session store.** Previously the
  `powerguesser.review_sessions` store was left behind on removal, so removing and re-adding
  PowerGuesser could restore an old open plug session — the remembered plug was re-tracked and, for
  a candidate target, silently subtracted from the remainder. The store is now removed with the
  config entry, so a re-add starts clean.

## Documentation

- A full documentation set now ships in `docs/` and the repository root: an expanded **README**
  (quick start and service examples), **ARCHITECTURE**, **CONFIGURATION**, **GETTING-STARTED**,
  **DEVELOPMENT**, **TESTING**, and a **CONTRIBUTING** guide.

## Install

Same as 0.2.0 — install or upgrade through the Home Assistant Marketplace ("Add from link" custom
repository, `https://github.com/hrabbach/ha-powerguesser`), then restart Home Assistant.

## Known limitations

Unchanged from 0.2.0: this is a **0.x release** (the hardware UAT is still open, so 1.0.0 comes
later); **30 s meters are the design baseline**; step detection needs an **effective interval of
45 s or less**; **program devices cannot be merged** in v0.x; and some device classes legitimately
read **not validated** until enough plug holdout events exist.

## Accuracy

Accuracy: see the README table, generated from the validation report; classes without a passing
